# Descriptive Statistics Analytics

## Overview

This project performs descriptive statistical analysis using Python in Jupyter Notebook. It explores a dataset by calculating measures of central tendency and visualizing the data to understand its distribution.

 Features

* Mean, Median, and Mode
* Data Cleaning
* Summary Statistics
* Data Visualization
* Python-based Analysis

 Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib

 Project Structure

* `DescriptiveStatistics_Analytics.ipynb` – Main notebook
* `requirements.txt` – Required Python libraries
* `README.md` – Project documentation
